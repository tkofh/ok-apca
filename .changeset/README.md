# Changesets

`@changesets/cli` generated this folder automatically. It is a build tool that versions and
publishes code in multi-package and single-package repos. Its full documentation is in
[the Changesets repository](https://github.com/changesets/changesets).

A list of common questions is in
[the Changesets documentation](https://github.com/changesets/changesets/blob/main/docs/common-questions.md).

`RELEASING.md` at the repository root describes how this repository uses Changesets to release.
